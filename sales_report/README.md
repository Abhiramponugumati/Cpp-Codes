# Sales Report

A small beginner-friendly Python project that reads sales data from `sales.csv`
and writes a short summary to `output.json`.

## What it does

- Reads sales records from a CSV file
- Calculates total sales
- Calculates average sales
- Finds the highest sale
- Saves the report as JSON

## How to run

From this folder, run:

```bash
python3 sales_report.py
```

After running the script, open `output.json` to see the results.

## Files

- `sales_report.py` - main Python script
- `sales.csv` - sample sales data
- `output.json` - generated report file

Note: this project intentionally includes two subtle logic bugs for practice.
